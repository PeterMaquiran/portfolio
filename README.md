A modern, minimalist, dark-mode portfolio website designed to showcase personal projects, technical stack, professional experience, and full-stack engineering work.

---

* **Docker Swarm**
* **Drone CI**
* **Gitea**

### Frontend
* **React / Next.js**
* **Vue**
* **Flutter**
* **Tailwind CSS**
* **Three.js**
* **Animations**

### Backend & Databases
* **Node.js**
* **Python**
* **NestJS**
* **PostgreSQL**
* **Go / Golang**
* **GraphQL**
